## 🚀 Sobre mim

Olá! Sou **Caio Martins**, estudante de **Desenvolvimento de Sistemas pelo SENAI**, com conclusão prevista para 2027.

Tenho interesse principalmente em desenvolvimento **Back-End e Full Stack**, com foco na construção de aplicações, APIs REST e integração com bancos de dados relacionais e não relacionais.

Atualmente, venho desenvolvendo projetos práticos utilizando PHP, PDO, PostgreSQL, JavaScript e Node.js, buscando aprofundar meus conhecimentos em arquitetura de software, organização de código e boas práticas de desenvolvimento.

### 🎯 Objetivos profissionais

- Conquistar uma oportunidade de estágio em Desenvolvimento de Software.
- Evoluir tecnicamente em desenvolvimento Back-End.
- Desenvolver aplicações escaláveis e bem estruturadas.
- Aprofundar conhecimentos em arquitetura de software e engenharia de software.
- Participar de projetos reais e colaborar com equipes de desenvolvimento.
